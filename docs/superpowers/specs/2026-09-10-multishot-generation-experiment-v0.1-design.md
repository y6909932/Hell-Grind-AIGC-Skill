# 多镜头真实生成实验 V0.1 设计

## 目标

在保留现有 `examples/minimal-short-film/` 单镜头回归样例不变的前提下，新增一个 4 镜头短片样例，验证资产锁定、镜头间状态交接、逐镜提示词、生成记录与后续真实视频模型验收的完整链路。

## 推荐方案

采用“新增并行消费者样例”而不是直接把现有单镜头样例改成多镜头。这样可以同时保留：

- 单镜头最小回归：证明 schema v2 的最低可运行路径；
- 多镜头连续性回归：证明跨镜头状态、提示词和生成记录可以稳定衔接。

V0.1 不把任何具体视频模型写死进核心 schema。真实生成由外部 Provider 完成，仓库只定义可移植的生成计划、记录格式和验收契约。

## 故事与镜头

沿用“雨夜维修站 / 梅 / 黄铜钥匙”设定，避免引入新角色和新道具。

### SC001-SH001｜建立空间

4 秒。梅站在半开的卷帘门下，黄铜钥匙在她右脚前方湿地面。镜头从中广景缓慢推进。结尾状态：她注意到脚边金属声，钥匙仍在地面。

### SC001-SH002｜拾取钥匙

4 秒。中近景。梅屈膝，以右手拇指和食指捏起钥匙。结尾状态：唯一一把钥匙已经转移到右手，卷帘门仍半开。

### SC001-SH003｜确认威胁方向

4 秒。偏中近景。梅起身，右手握钥匙，视线转向道路左侧。结尾状态：右手持钥匙、人物警觉、道路左侧成为注意方向。

### SC001-SH004｜收束动作

4 秒。后侧三分之四中景。梅向雨棚内后退半步，但保持右手持钥匙、视线仍指向道路左侧。结尾状态：人物处于警戒等待，不新增人物、车辆或第二把钥匙。

总时长 16 秒。

## 连续性契约

每个相邻镜头都显式写出完全相同的 `continuity_out` / `continuity_in` 交接状态。V0.1 锁定以下变量：

- 角色：始终只有梅一人；
- 道具：始终只有一把黄铜钥匙；
- 持有状态：SH001 结束仍在地面；SH002 起从地面转到右手；SH003/SH004 始终在右手；
- 场景：卷帘门始终半开；
- 服装：深蓝湿工作服不变化；
- 屏幕方向：从 SH003 起，梅的注意方向保持道路左侧；
- 环境：夜晚、雨后、雨棚滴水持续。

## 生成记录

`06_generations/generation-log.csv` 继续使用现有 schema，不预填虚构的成功生成记录。真实 Provider 执行后才写入：

- provider / model / seed / parameters_json；
- output_path；
- cost / currency；
- failure_codes；
- status。

在真实模型尚未执行前，仓库只维护可直接提交给 Provider 的逐镜 master prompt 与 prompt index。

## Prompt 设计

每个镜头使用独立 master prompt，沿用现有 L1～L7 层次：主体与数量、镜头时长、摄影机、动作表演、环境与材质、连续性硬约束、Provider 适配层。

所有 prompt SHA256 使用规范化 UTF-8/LF 文本哈希。

## 验证

新增自动化测试覆盖：

1. 多镜头样例 `--strict-v2` 通过且 `shots == 4`、`prompts == 4`；
2. 四份 master prompt 均通过视频 Prompt Auditor；
3. 四个 prompt-index 哈希与实际文件一致；
4. 相邻镜头 `continuity_out == continuity_in`，验证器不产生 `CONTINUITY_HANDOFF_MISMATCH`；
5. 多镜头样例保留 3 个已锁定资产，不引入未声明资产；
6. 全仓库普通 pytest 在 Linux GitHub Actions 通过；
7. Windows 本地 Runner 继续作为跨平台验证通道。

## 非目标

V0.1 不做以下内容：

- 不在仓库内绑定 Higgsfield、Runway、Seedance、Kling 等单一模型 API；
- 不伪造真实生成结果；
- 不把视觉语义连续性等同于当前文本契约连续性；
- 不增加自动付费、自动提交生成任务或自动下载媒体；
- 不删除或改写现有单镜头 `minimal-short-film` 回归样例。

## 完成标准

当 4 镜头样例在 Linux CI 和 Windows Runner 均通过、四份 Prompt 均通过结构审计，并且真实 Provider 已有可连接通道时，仓库进入“可执行真实生成”状态。实际视频生成成功与视觉连续性验收属于下一层运行证据，不在没有 Provider 连接时冒充完成。
